## 1. 끝낸 것

| 항목 | 내용 |
|---|---|
| 연구 방향·제목 | 피드백대로 방향 1(영상 열화 분석)로 진행, 방향 2(Synthetic-to-Real)는 후속 연구로. "성능 붕괴" 표현을 빼고 제목을 **"CCTV 영상 열화에 따른 교통사고 탐지 AI의 성능 저하 및 취약성 분석"** 으로 수정 |
| 관련연구 확보 | ACCIDENT, Cai 등(2025), O'Byrne 등(2022), 윤영두·김호(2026) 4편 **원문 확인 완료**. 시점·위치를 나눠 보는 근거로 Poyser 등(2021) 추가 |
| 팀 공유 자료 | ACCIDENT·Cai 논문 정리 파일 (논문 요약 / 우리 연구와 차이점 / 적용할 점) |
| 서론 | 4문단 초안을 학회 양식(IEEE)에 넣어 10/7 제출 |
| 데이터셋 | ACCIDENT 다운로드, 데이터 구조와 원본 영상 확인. 설계상 평가 대상은 실제 CCTV 영상 중 테스트 묶음(IID 테스트) 1,520개. 실제로 돌리는 pilot은 이 중 50~100개 |
| 모델 | Molmo-7B-D zero-shot. ACCIDENT 논문의 baseline 중 가장 성능이 좋았던 모델이고, 공식 코드에서 같은 모델임을 확인 |
| 열화 요인 선정 | 해상도 저하, H.264 압축, 모션 블러. 선정 기준은 "카메라 촬영·영상 전송 과정에서 생기고, 통제해서 재현할 수 있는 열화" (날씨·가림은 장면 조건이라 제외, 저조도는 합성으로 재현하기 어려워 제외) |

## 2. 하고 있는 것

| 항목 | 상태 |
|---|---|
| II. 관련연구 | 1문단(영상 열화와 AI 성능) 초안 작성. 2문단(ACCIDENT와 본 연구의 위치) 남음 |
| 서론 수정 | 설계 중심 논문이 되면서 4문단의 "정량적으로 보인다"를 "비교하기 위한 분석 체계를 제시한다"로 고치기로 함 |
| 열화 단계 수치 | 해상도 1/2·1/4·1/8 안. 압축 CRF 구간은 미정. 모션 블러는 차량 속도 × 셔터 시간으로 계산하는 방식 검토 중 → **오늘 질문 5번** |
| 평가 방식·지표 | 위치는 정답 사고 장면을 주는 오라클 보조 방식, 비교는 원본 대비 하락률(RPD) + 짝지은 부트스트랩 신뢰구간 → **오늘 질문 6·7번** |

## 3. 아직 시작 전

- pilot test: 1,520개 중 50~100개로 원본 성능 재현(논문 수치 시점 0.343, 위치 0.596과 비슷한지 확인) → 열화 적용
- III. 연구 설계, 전체 분석 구성도(Fig. 1)
- IV. 분석 계획 및 기대 결과, V. 결론, 요약
- 포스터 (양식 공지 대기)

## 4. 팀에서 임시로 정한 것 (오늘 확인받을 것)

| 항목 | 임시 결정 | 이유 |
|---|---|---|
| 논문 언어 | 한국어 | 양식이 영어(IEEE)라 확인 필요 |
| 판단 능력 | 시점(When)·위치(Where)만. 유형(What)은 제외하고, "유형별로 시점·위치 성능이 다른지" 보는 하위 분석에만 사용 | Molmo 원본 유형 정답률 0.271이 가장 흔한 유형만 찍는 기준선 0.335보다 낮아서, 열화 영향을 측정하기 어려움 |
| 실험 범위 | 설계 중심 + pilot 결과를 예비 결과로 추가 (마감이 늦춰져 pilot은 일정에 넣음) | 전체 실험은 영상 1,520개 × 조건 10개 × 영상당 시점 질의 약 50회로 추론량이 큼 |
| 저자 | 이우석, 안한석, 안동현 | — |

자세한 질문은 [교수님_미팅_질문.md](교수님_미팅_질문.md), 5~7번 근거는 [교수님_미팅_5-7번_근거설명.md](교수님_미팅_5-7번_근거설명.md) 참고.
