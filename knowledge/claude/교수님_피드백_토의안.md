# 교수님 피드백(2026-10-13) 토의안

이우석과 토의하며 정하는 문서. 2026-10-13 결정은 [결정사항.md](결정사항.md)에 반영함 (pilot 대신 실제 영상 실험(영상 수는 실험 스레드에서 확인 중), 한국어 확정, 수식은 모션 블러 길이 식).

## 피드백이 바꾸는 큰 그림

교수님이 말씀하신 구성은 **I. 서론 → II. 관련연구 → III. 연구방법 → IV. 실험결과 → V. 결론**이다.
우리 기존 계획은 IV장이 "분석 계획 및 기대 결과"(설계 중심)였는데, 5번 피드백이 "실험결과에 비교표나 그림"이라 **실제 결과(pilot)가 들어가는 논문**으로 읽힌다. 이게 맞으면 pilot이 "예비 결과"가 아니라 IV장 본문이 된다. → 질문 1

## 항목별 제안

### 1. 서론 절반으로
- 남길 것: ① CCTV 기반 사고 탐지 AI가 쓰이고 있다 ② 실제 CCTV 영상은 해상도·압축·흔들림으로 품질이 떨어진다 ③ 그런데 열화에 따라 성능이 얼마나 떨어지는지는 잘 알려져 있지 않다 ④ 본 연구는 ACCIDENT 영상에 열화를 적용해 시점·위치 판단 성능 변화를 분석한다.
- 뺄 것: 세부 수치(0.343, 0.596 등), 열화 단계 수치, 지표·통계 설명, 기여 목록의 상세. 이런 건 III·IV장으로 보낸다.
- 4문단 → 2문단(문제·공백 1문단 + 본 연구 1문단) 안.
- **서론 초안 파일이 프로젝트에 없어서 받아야 함.**

### 2. 인용할 때 간접적으로
- 피할 표현: "A는 ~을 고려하지 않았다", "A의 한계는 ~이다", "A는 실제 환경을 반영하지 못한다".
- 바꿀 방식: 상대 논문이 **한 일**을 쓰고, 우리 연구를 **확장**으로 놓는다.
  - 예) "ACCIDENT는 열화 조건을 고려하지 않았다" → "ACCIDENT[1]는 실제 CCTV 영상 기반의 사고 판단 벤치마크를 제시하였다. 본 연구는 이를 영상 품질이 저하된 조건으로 확장하여 분석한다."
  - 예) "O'Byrne은 객체 검출만 다루었다" → "O'Byrne 등[3]은 영상 압축이 객체 검출 성능에 미치는 영향을 분석하였으며, 본 연구는 이러한 관점을 사고 시점·위치 판단으로 넓힌다."
- 관련연구 초안을 주면 문장 단위로 고쳐 줄 수 있음.

### 3. 관련연구: 수식 0~1개, 우리가 쓰는 기법 위주
- 해석: 남의 논문 비평보다 **우리가 쓰는 도구를 설명하는 장**으로 바꾸라는 뜻.
- 구성 안:
  - 2.1 ACCIDENT 벤치마크와 Molmo-7B-D (데이터, 시점·위치 과제 정의, zero-shot 질의 방식)
  - 2.2 영상 열화 기법 (해상도 저하, H.264 압축과 CRF, 모션 블러) — O'Byrne, Cai, 윤영두·김호, Poyser는 여기서 "이 기법을 이렇게 썼다"로 짧게 인용
- 수식 후보 (1개만 넣는다면):
  - (a) 모션 블러 길이: L = v · t / s (속도 × 셔터 시간 ÷ 픽셀당 거리) — 우리 열화 단계의 근거라 의미 있음 **← 추천**
  - (b) 넣지 않음 — RPD는 III장 평가지표 표로 보냄
- → 질문 3

### 4. 연구방법: 전체 분석 절차 그림 + 평가지표 표
- Fig. 1 (흐름도): ACCIDENT 테스트 영상 → 열화 적용(3종 × 3단계 + 원본) → Molmo-7B-D zero-shot 질의(시점, 위치) → 지표 계산 → 원본 대비 하락률 비교
- 표 1 (평가지표, 간단히):

  | 과제 | 지표 | 의미 |
  |---|---|---|
  | 시점(When) | ACCIDENT 공식 시점 지표 (원본 0.343) | 예측 사고 시점이 정답에 얼마나 가까운가 |
  | 위치(Where) | ACCIDENT 공식 위치 지표 (원본 0.596) | 예측 사고 위치가 정답에 얼마나 가까운가 |
  | 비교 | 상대 하락률(RPD) | (원본 − 열화) / 원본 × 100 |

  (지표 정식 이름·정의는 ACCIDENT 논문 원문에서 확인 후 채움)
- 열화 단계 수치도 표 하나로 같이 보여줄 수 있음 (표 2: 열화 종류 × 단계).

### 5. 실험결과: 비교표나 그림, 간단히
- 안: 표 1개 + 그림 1개
  - 표: 행 = 원본·열화 9조건, 열 = 시점 점수, 위치 점수, 각 RPD
  - 그림: x축 = 열화 단계(0~3), y축 = 성능, 선 = 열화 종류 3개 (시점·위치 2패널)
- 해석 문단은 2~3문장: 어떤 열화에 가장 약한지, 시점과 위치 중 어느 쪽이 더 민감한지.

### 6. 결론 7줄 정도
- 틀: ① 무엇을 했다(1~2줄) ② 무엇을 보였다/기여(2줄) ③ 한계(1~2줄) ④ 향후 연구(1~2줄)
- 한계 후보: pilot 표본 규모, 단일 모델(Molmo), 합성 열화(실제 열화와 차이), 유형(What) 제외
- 향후 연구 후보: 전체 1,520개·다른 VLM 확장, 열화에 강건한 학습/복원 전처리, Synthetic-to-Real(방향 2)
